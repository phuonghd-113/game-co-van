Đồng bộ dữ liệu Sự kiện và Ngân hàng câu hỏi lên đám mây Google Firebase hoàn toàn miễn phí. Soạn đề ở nhà trên máy cá nhân, lên lớp mở máy chiếu là thấy ngay!

Link cơ sở dữ liệu lấy từ Firebase Console (Realtime Database → Data URL)
HƯỚNG DẪN 3 BƯỚC TẠO FIREBASE MIỄN PHÍ VĨNH VIỄN:
  1. Truy cập console.firebase.google.com, đăng nhập bằng Gmail và bấm Tạo dự án mới (Ví dụ: olympia-lop-hoc).
  2. Vào mục Build → Realtime Database → Bấm Create Database → Chọn Start in test mode (hoặc Rules: ".read": true, ".write": true).
  3. Sao chép đường link dạng https://...-default-rtdb.firebaseio.com/ dán vào ô Database URL phía trên và bấm Lưu và Đẩy lên Đám mây.
